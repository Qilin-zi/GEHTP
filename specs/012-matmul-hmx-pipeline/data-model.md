# Data Model: MatMul HMX 流水线

## 实体

### 1. HMX 会话（HMX session）

一次 acquire→release 的生命周期，覆盖整段 tile 走查（而非单个 tile）。

| 字段 | 类型 | 说明 |
|---|---|---|
| 状态 | enum | `空闲` / `已获取` / `流水执行` / `已释放` |
| 覆盖范围 | (n_row, n_col) | 本会话内执行的 tile 面 |
| 持锁层 | enum | spinlock + HAP resource lock 两层 |

**状态转换**: `空闲 → 已获取`（acquire）→ `流水执行`（逐 tile mxclracc/mxmem/MAC）→ `已释放`（release）→ `空闲`。

**校验规则**: 一次会话内不允许嵌套 acquire；异常路径必须释放（FR-008 复位）。

### 2. 暂存区（Staging buffer）

片内持有权重、供 HMX 流式读取的区域。

| 字段 | 类型 | 说明 |
|---|---|---|
| 基址 | 指针 | VTCM 内偏移（2048 对齐） |
| 大小 | uint32 | 权重字节数 |
| 占用态 | enum | `空闲` / `写中(DMA)` / `就绪` / `读中` |
| 所属权重 | 槽 id | 当前缓冲内容对应哪个权重槽 |

**校验规则**: 至少两个独立暂存区（乒乓），搬入其一不得覆盖「读中」的另一个（FR-002、FR-006）。

### 3. 权重搬运（Weight transfer）

一次片外→片内搬运。

| 字段 | 类型 | 说明 |
|---|---|---|
| 源 | 偏移 | 片外权重区偏移 |
| 目标 | 暂存区 | 上述暂存区之一 |
| 大小 | uint32 | 字节数 |
| 完成态 | enum | `未发起` / `已提交` / `已完成` |

**状态转换**: `未发起 → 已提交`（dc_dma_submit 异步触发）→ `已完成`（dc_dma_wait poll 到 dstate=complete）→ 消费后 `未发起`。

**校验规则**: 「已完成」之前不得被 HMX 读取（FR-003 use-before-ready 屏障）；提交前源区已 clean、完成后目标区已 invalidate。

### 4. 预取描述符 / 前瞻记录（Prefetch descriptor）

对「下一个 matmul 的权重及其搬运」的记录，用于提前发起。

| 字段 | 类型 | 说明 |
|---|---|---|
| 目标 op | 索引 | 前瞻到的下一个 matmul |
| 权重槽 | 槽 id | 其权重槽（含 w_pp / w_q4 / 裸 f16 形态） |
| 搬运引用 | 权重搬运 | 关联的搬运实体 |
| 有效 | bool | 前瞻是否命中可预取 matmul |

**校验规则**: 前瞻非 matmul 或无目标时 `有效=false` → 回落串行（FR-007）。

### 5. 累加器边界（Accumulator boundary）

流水化后每个 tile 累加开始前的复位点。

| 字段 | 类型 | 说明 |
|---|---|---|
| 复位指令 | — | `mxclracc.hf`，每 tile 一次 |
| 部分和归属 | tile 索引 | 累加结果对应当前 tile，不跨 tile 残留 |

**校验规则**: 每个 tile 累加开始前必须复位；读出顺序改变不改变输出元素值（FR-003、FR-004）。

## 关系

- 一个 **HMX 会话** 覆盖多个 tile，每个 tile 触发一次 **累加器边界复位**。
- 一个 **权重搬运** 写入一个 **暂存区**；一个暂存区在任一时刻最多被一个搬运占用。
- 一个 **预取描述符** 引用一个 **权重搬运**，提前于其消费方 matmul 发起。
- 暂存区在「读中」态不可被「写中」态占用（乒乓保证）。
